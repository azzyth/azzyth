## About Me

I am a Data Science student at Telkom University working mostly on machine learning problems that arrive with real constraints: messy text, imbalanced labels, drifting time series, and leaderboards that do not forgive a leak. Most of what I know comes from Kaggle competitions and Indonesian data-mining contests, where I build the pipeline end to end: parsing, feature engineering, validation design, and ensembling.

Current focus: pushing the same work past the notebook, into databases, APIs, containers and CI pipelines, so that a model ends up as something people can actually open and use.

Telkom University, Indonesia
